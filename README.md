# Jeu de rythme

Petit jeu de rythme familial, inspiré de Theatrhythm, à jouer au doigt sur téléphone.

**Jouer :** https://kikitmt-bit.github.io/jeu-rythme/

- Téléphone en paysage, son allumé. On touche n'importe où, avec un doigt ou les deux pouces.
- Rouge : taper. Vert : maintenir, lâcher au bout. Jaune : glisser dans le sens de la flèche. Trait doré : deux doigts en même temps.
- La première fois, le jeu demande le mot de passe familial (il déverrouille les musiques).
- Pour l'avoir comme une appli : menu du navigateur → « Ajouter à l'écran d'accueil » (iPhone : Partager → « Sur l'écran d'accueil »).

Projet personnel, non commercial. Les musiques appartiennent à leurs auteurs et ne sont stockées ici que chiffrées, pour un usage familial.
